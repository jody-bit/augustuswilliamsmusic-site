                    AUGUSTUS WILLIAMS MICROSITE
                    ==========================
                    
A cinematic, underground-aesthetic website for Detroit techno artist Augustus Williams.

PROJECT FILES
=============

📄 index.html           Main website HTML
                        - Hero section with portrait
                        - Biography & format info  
                        - Press archive (4 items)
                        - Session index (4 sessions)
                        - Contact/booking channels
                        - Footer

🎨 styles.css           All typography, layout, colors
                        - Dark aesthetic (#0a0a0a background)
                        - Cream typography (#f5f1eb)
                        - Red accent system (#d32f2f)
                        - Responsive breakpoints
                        - Subtle animations

⚡ script.js            Client-side interactions
                        - Smooth scroll navigation
                        - Scroll-based animations
                        - Parallax image effect
                        - Active nav state
                        - Hover effects

📁 assets/              Image directory
                        - Place hero.jpg here (3:4 aspect)
                        - Keep images optimized <200KB

📚 README.md            Comprehensive documentation
                        - Design philosophy
                        - Customization guide
                        - Performance notes
                        - Deployment options
                        - Accessibility checklist

⚙️ QUICKSTART.md         Fast setup guide
                        - Local testing commands
                        - Content editing (no code!)
                        - Image setup
                        - Deployment to Vercel/Netlify
                        - Troubleshooting

🔧 SNIPPETS.md          Copy-paste customization code
                        - Add press items
                        - Add sessions
                        - Change colors/fonts
                        - Add contact form
                        - Advanced techniques


QUICK START
===========

1. TEST LOCALLY
   cd augustuswilliamsmusic-site
   python -m http.server 8000
   → Open http://localhost:8000

2. EDIT CONTENT
   Open index.html in any text editor
   Update email, links, session names
   No coding required!

3. ADD IMAGE
   Export 3:4 portrait from EPK
   Optimize with TinyPNG.com
   Save as assets/hero.jpg

4. DEPLOY
   Choose: Vercel, Netlify, or GitHub Pages
   Push code, add custom domain
   DNS setup (24-48 hours)

FILE CUSTOMIZATION
==================

  Replace with your actual email

  In Contact section, update href="#" with real URLs

  Update with actual press mentions and dates

PERFORMANCE
===========

HTML + CSS + JS: ~33 KB (uncompressed)
With optimized hero image: ~200 KB total

This is excellent web performance.

Optimization tips:
  • Compress images to <200KB
  • Use WebP format if possible
  • Test with PageSpeed Insights
  • Monitor Core Web Vitals

DESIGN DECISIONS
================

Why no web fonts?
  → Faster loading, works offline, zero layout shift

Why minimal JavaScript?
  → Better performance, no framework overhead

Why monospaced headers?
  → Editorial aesthetic, underground archive feel

Why red accents on black?
  → High contrast, iconic in techno design, visual hierarchy

Why single page?
  → Everything about Augustus in one experience
  → No page load friction
  → Better for music artist portfolio
